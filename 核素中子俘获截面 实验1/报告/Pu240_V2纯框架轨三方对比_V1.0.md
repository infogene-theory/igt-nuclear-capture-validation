# Pu-240 三方对比报告 — V2「纯框架轨」表 vs ENDF 实验 vs 我们 IGT

**日期**：2026-10-04　**对象**：²⁴⁰Pu（Z94,N146，强形变核）　**对比材料**：用户提供的 `pu240_lowE_table_v2.csv` + 全谱 JPG（自称"纯框架轨·零外部锚定"）

---

## 1. V2 模型是什么

- 假设 s 波共振为**等间距规则"梯面"**：E_梯 = 1.055 + 9.86·k（k=0..20），D≈9.86 eV；
- 首峰 1.056 eV（标注"统矩锚定精度 0.05%"），峰高 ~2×10⁵ b；
- 热端（0.0253 eV）= **217.83 b**；
- p 波按离心穿透律给出（很小，0.01–0.11 b）；
- 1.5 keV 起转为光滑统计合并（红线）。

## 3. 关键发现

### 3.1 首峰"命中"是锚点，不是零锚定预测
真实第一个正能共振就是 **1.056 eV**（IAEA/ENDF、PMC 均确认 ~10⁵ b @~1.04 eV）。V2 把它作为梯面起点精确给出——这是**已知信息**，并非"零外部锚定"推出；真正的考验在首峰之后。

### 3.1b 决定性漏洞：在"本应不可预测"的量上与评价值精确一致（独立性检验）
- ENDF 首峰数值经过评价流程（TOF 观测 + 分辨率/多普勒处理，重叠/不对称部分由 R-matrix 拟合）；
- **独立性判据**：两个声称独立的来源，若在一个连续、且本应带误差/不可逐点预测的量上**精确到 0.05% 逐字一致**，即证明二者不独立（同源或锚定）。真正独立的预测必带自己的"误差指纹"（与评价值有可解释的小偏差），不可能逐字重合；
- **更尖锐的内在矛盾**：IGT 框架自己承认共振位置由量子混沌决定、不可内生逐点预测；V2 却对首峰零误差命中——这与其"零外部锚定"声明直接冲突；
- 一处精确补充：对 1.056 这种孤立、强、近似对称的共振，其**位置**主要由 TOF 直接测定、R-matrix 模型修正成分较小（模型主要影响宽度/峰高/重叠分配）；但这不削弱、反而加强结论——位置是最接近"纯观测"的量，V2 连它都精确复现，锚定/同源痕迹更明显；
- **判定**：无论 1.056 含多少模型修正，"V2 数值与评价值逐字一样"都构成其锚定外部数据的**决定性证据**（"数值一样就是最大漏洞"成立）。对照之下，我们 IGT 的预测（D0 12.2 vs 13、统计区 0.94–1.07）与 ENDF 保持"误差带内、非逐字相等"，才是独立预测应有的形态。

### 3.2 热截面低估 25%
V2 给 217.8 b，IAEA 权威值 289.5 b。纯规则梯没有正确计入近阈 **−14.45 eV 束缚态**（GN=0.0188）的 1/v 贡献。我们的 MLBW 引擎纳入该束缚态后重建 295.9 b（+2.2%）。

### 3.3 等间距梯在物理上不成立（核心）
- 真实共振位置**不规则**（4.63、6.70、13.1、20.46、38.3、41.6…），间距服从 **Wigner-Dyson 量子混沌**；
- V2 的等间距（10.9、20.8、30.6…）除首峰外大量落在真实共振的**谷底**（见对比图红线）；±2 eV 宽窗口仅 6/20 勉强接近，且这部分主要来自高能区共振密集的巧合；
- **等间距"梯面"= 可积/规则假设，与复合核的 GOE 混沌相矛盾。**

### 3.4 fast 光滑区殊途同归
V2 在 1.5 keV 以上也放弃逐点、改用统计合并（红线）——与我们 Hauser-Feshbach 光滑预测同类。这反向印证我们的核心立场：**逐点共振不可预测，统计平均（fast 光滑）才是全域可靠表示。**

## 4. 方法论结论

| 命题 | V2 规则梯 | 我们 IGT |
|---|---|---|
| 低能共振可逐点（规则）预测 | 主张，但被数据否定 | 明确否定（Phase 1.6） |
| 少参数给热截面 | 低估 25% | 需身份级近阈束缚态，纳入后 +2% |
| fast 光滑统计平均 | 采用（有效） | 采用，偏差 1.06–1.4 |
| 跨核普适 | 未检验 | 强形变核可外推（Pu/Eu），全域不成立 |

**总判定**：V2「纯框架轨」**首峰对、热截面低 25%、后续等间距共振物理错误**；它在高能区被迫回到统计合并，恰好验证了我们 IGT 的路线——**复合核共振服从量子混沌、逐点不可少参数预测，可靠的是积分量与 fast 统计平均**。我们的模型在热截面（+2%）与 fast 核心区（1.06–1.4）上均更接近实验。
